# 袋研官中文化、品牌替换与素材扫描修复设计

## 目标

将所有用户可见的功能文案统一为简体中文，产品名称统一为“袋研官矩阵混剪工作台”，使用用户提供的“袋研官 BAG LAB”标识替换界面、窗口、安装包和快捷方式图标，并修复安装版素材目录选择时预加载桥接缺失的问题。

## 技术设计

1. 保持 `contextIsolation: true`、`nodeIntegration: false` 和 `sandbox: true`，通过 Electron Vite 将预加载脚本所依赖的 `zod` 打入单文件，确保安装环境无需从沙箱加载外部 Node 模块。
2. 增加渲染层桥接守卫与中文错误格式化器。桥接异常、IPC 异常和后端英文异常不得直接展示给用户，界面提供中文原因与下一步操作。
3. 定义中文 Electron 原生菜单，替换默认英文 `File / Edit / View / Window`。
4. 统一品牌常量与界面文案：产品名为“袋研官矩阵混剪工作台”，宣传语为“本地优先内容生产引擎”。
5. 从用户提供的方形黄色 Logo 原图生成 PNG 与 ICO 多尺寸资源；侧栏使用适配深色背景的 Logo 图，Windows 可执行文件、安装程序、桌面快捷方式使用同一 ICO。
6. 以测试驱动实现，并在源码测试、打包预加载审计、未打包应用、安装包和真实安装应用五个层级验证。

## 验收标准

- 素材中心可以打开目录选择器；取消选择不报错，选择分类目录后可扫描并展示结果。
- 预加载桥接缺失时显示中文提示，不出现 `Cannot read properties of undefined`。
- 顶部原生菜单、页面按钮、提示、状态和常见业务异常均为中文。
- 左上角、窗口标题、程序列表、安装包、桌面快捷方式均显示“袋研官矩阵混剪工作台”及袋研官 Logo。
- 安装包在 Windows 11 x64 可启动，桥接对象包含 `selectAndScanAssets`。
