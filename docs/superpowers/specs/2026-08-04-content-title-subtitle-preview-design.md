# 内容标题、字幕排版与成片预览闭环设计

## 目标

本轮把选题、文案、镜头、任务和成片从页面级拼接改为一条可追踪的数据主线，同时修复字幕越界、字体不全、预览不可播放、临时文件污染成品目录等问题。

核心结果：每条内容只有一个冻结的 5–8 字短标题；任务创建后使用不可变快照；成品目录只出现以短标题命名且验证可播放的 MP4。

## 内容数据主线

选题结构调整为：

```ts
type TopicCandidate = {
  id: string;
  shortTitle: string;   // 5–8 个中文字符
  description: string;  // 选题方向和论述重点
  hook: string;         // 开场切入角度
};
```

`shortTitle` 写入文案项目的 `mainTitle`，贯穿文案库、镜头剪辑、任务列表、发布资料和成品文件名。`description` 写入选题详情，仅用于指导详细文案生成。旧数据缺少短标题时执行一次兼容推导，但新数据禁止继续从长标题临时截取。

模型提示词和结构校验共同保证：

- 短标题为 5–8 个中文字符；
- 文案是可直接朗读的第一人称或对观众直述台词；
- 不出现括号动作、舞台提示、镜头说明或旁白标记；
- 不虚构人设资料之外的事实、数字、案例和承诺。

模型结果进入文案库前执行确定性净化，移除 `（叉腰）`、`【停顿】`、`镜头切换：` 等非口播标记。归档文案重新编辑时不原地修改，而是复制为新版本并回到文案库；历史任务快照和成片不变。

## 选题交互

生成选题期间显示不确定进度条、阶段说明和已耗时，所有生成入口锁定，避免重复提交。选题列表右上角增加“全选/取消全选”。

每张选题卡明确显示：短标题、选题详情和开场角度。换一批不会覆盖已经保存的文案项目。

## 字幕语义折行

最终字幕不能依赖 libass 自动折行。前端预览和 Python 导出共用同一组排版参数与测试样例，后端是最终权威实现。

折行顺序：

1. 根据字号、缩放、字间距、描边和 1080 画布安全区估算单行容量；
2. 优先在句号、问号、感叹号、分号、逗号、顿号和语义短语边界折行；
3. 避免拆开数字、英文串、品牌名和连续词组；
4. 没有自然边界时才按字符安全拆分；
5. 默认最多两行，超出两行时按持续时间拆成连续字幕事件，而不是继续缩小或越界。

ASS 写入显式 `\N`，同时设置安全边距。标题使用同一套宽度约束，但通常保持单行。

## 字体扫描

字体列表合并以下来源并去重：

- `C:\Windows\Fonts`；
- 当前用户字体目录；
- 系统和当前用户字体注册表；
- 用户手动选择的字体文件。

支持 TTF、OTF、TTC、OTC、FON 和 FNT。对 TTC/OTC 解析内部字体族名，避免一个集合文件只显示一个错误名称。无法解析的旧字体保留文件名回退项，但不会阻断页面加载。

## 样式预览

镜头剪辑右侧预览默认使用用户提供的模糊工厂图，仅作为字幕样式背景，不写入成片。预览增加背景图/深色背景切换、安全区和实际两行折行，标题、透明度、描边与阴影即时同步。

音频设置页面删除人声音量。人声音量与 BGM 音量继续集中在镜头剪辑页，并在创建任务时冻结到快照。

## 任务中心与媒体预览

任务中心使用左右分栏：左侧为收紧列宽的任务表，右侧为固定 9:16 播放器。滚动任务列表不移动播放器，点击已完成任务即可切换预览。

播放器统一使用主进程注册且经过路径白名单校验的媒体协议，正确处理中文、空格、井号等路径字符。CSP、协议注册和 Renderer URL 使用同一个 scheme，禁止 Renderer 直接读取任意文件。

任务中心顶部增加“打开成品文件夹”。用户描述的“人物中心”按截图和上下文解释为“任务中心”。

## 输出与临时文件

成品目录只保留最终 MP4：

```text
成品目录/短标题.mp4
```

ASS、配音缓存、FFmpeg 日志和 partial 文件放到：

```text
工作目录/tasks/{taskId}/
```

成片通过 ffprobe 验证后删除可重建的 ASS 和 partial 文件；失败时保留诊断文件在任务工作目录。文件名移除 Windows 非法字符，同名使用 `（2）`、`（3）`，任务重试保持快照中冻结的文件名。

## 字幕动画边界

本轮不启用字幕动画，优先保证折行、预览和批量合成稳定。后续可基于 ASS/libass 分阶段加入：

- 淡入：`\fad`，成本最低；
- 左滑：`\move`，成本较低；
- 打字机：逐字符事件或卡拉 OK 标签，事件数和编码开销较高。

若后续实施，先开放“无动画、淡入、左滑”，打字机在真实 30–60 秒视频基准测试通过后再作为实验选项。

## 兼容与迁移

- 旧任务、旧成片和旧归档记录不删除；
- 旧任务继续显示原快照标题和路径；
- 新任务一律冻结短标题和最终输出文件名；
- 归档编辑创建新版本，不反向修改旧任务；
- 新增字段提供迁移默认值，数据库升级可重复执行。

## 验收标准

1. 生成选题期间有进度、耗时和防重复提交。
2. 可一键全选或取消全选 5 条选题。
3. 每条选题包含 5–8 字短标题和独立详情。
4. 新生成文案不包含动作括号或镜头指令。
5. 归档文案可复制为新版本编辑，历史任务不变。
6. 1080×1920 长字幕不越出安全区，最多两行；更长内容拆成连续事件。
7. Windows 系统与用户安装字体完整可选，字体集合可识别。
8. 编辑预览可在工厂图和深色背景间切换。
9. 任务中心右侧固定播放器可播放中文路径成片。
10. 成品目录没有 ASS、partial 或 UUID 命名产物。
11. 选题、文案、任务、发布资料和 MP4 文件名使用同一短标题。
12. 既有自动测试通过，并用真实素材完成连续成片与播放验收。
