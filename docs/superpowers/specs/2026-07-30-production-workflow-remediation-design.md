# 袋研官生产工作流修复与界面重构设计

## 目标

修复 0.2.0 中创作链路“点击无反馈、功能入口不完整、镜头区不可用、发布账号只有记录没有登录”的问题，并建立一致的黄黑白桌面端 UI 规范。最终流程仍为：人设 → 文案 → 音频 → 镜头剪辑 → 创建任务。

## 已确认的根因

1. 文案页的异步生成函数只在 `finally` 中关闭 loading，没有 `catch`，百炼密钥缺失、模型不存在、网络超时和返回格式异常都会变成无反馈。
2. DeepSeek 已经通过百炼 OpenAI-compatible 接口接入；模型名由设置页配置，不应在界面翻译。
3. MiniMax 声音克隆后端与 IPC 已存在，但上传样本入口藏在二级弹窗，音频主界面缺少清晰的“上传并克隆音色”工作流。
4. 镜头由音频段落派生。音频段落为空或草稿恢复异常时，镜头区没有空状态修复入口；模板卡片只负责套用，不具备完整编辑动作。
5. 当前字体功能只支持手选单个字体文件，没有扫描 `C:\Windows\Fonts` 与用户字体目录。
6. 发布账号创建只写数据库，登录检测要第二次点击；用户无法理解创建和登录之间的关系。
7. 参考脚本列表没有展开、预览与编辑状态。
8. 侧边栏没有 sticky/fixed 约束，长页面会把导航滚出视口。

## 交互架构

### 统一异步任务反馈

所有耗时操作使用同一状态模型：

- `idle`：可操作。
- `validating`：校验本地配置。
- `requesting`：向百炼、MiniMax 或本地服务发起请求。
- `processing`：服务端生成或本地扫描。
- `success`：完成并展示结果。
- `error`：展示中文原因、建议动作和“重试”按钮。

无法获得真实百分比的远程请求使用阶段式进度条，不伪造精确进度。错误信息必须映射为用户可执行建议，例如“前往系统设置配置百炼 API Key”“模型 deepseek-v3 不可用，请更换模型”。

### 文案生成

- 保留人设和模型选择。
- 生成选题时显示阶段文本与进度条，成功后展示五个选题。
- 失败后在选题区域内展示错误卡片和处理按钮，另发中文消息提示。
- 换一批、生成完整文案、违禁词检查使用同一反馈模式。
- DeepSeek 与 Qwen 等模型名保持原文。

### 音频制作

布局参考用户提供的配音页，但使用袋研官黄黑白配色：

- 顶部：音色搜索、刷新、上传声音样本、音色试听。
- 主体：音色下拉与音色卡片、情感下拉、模型、语速、音量、音调。
- 情感值提交给 MiniMax 时保持英文枚举，界面显示中文。
- 声音名称优先使用 MiniMax 返回名称；已知系统音色映射为中文，未知名称保留原名。
- 上传区明确展示格式、时长、大小校验、样本路径、克隆 ID、生成进度和错误恢复。
- 底部保留逐段音频列表、单段试听/重试和全部生成进度。

### 镜头剪辑

采用稳定三栏工作台：

- 左栏 260px：模板列表、当前模板名称/说明、应用、复制、新建、保存。
- 中栏最小 560px：从文案或音频重新构建镜头、添加镜头、逐镜头编辑、素材分类、时长、静音、排序和删除。
- 右栏 420px：至少 252×448 的 9:16 预览、BGM、字体、标题、字幕样式。
- 没有音频段落时仍显示可操作空状态，可从文案重新拆分镜头。
- 表单控件不得互相覆盖；数字步进器与字体按钮分行布局。
- 预览默认取消重阴影，使用清晰的细描边；所有设置实时预览。

### 本机字体库

Electron 主进程扫描：

- `C:\Windows\Fonts`
- `%LOCALAPPDATA%\Microsoft\Windows\Fonts`

支持 `.ttf`、`.otf`、`.ttc`。返回字体文件路径、显示名称和 CSS family。界面以可搜索下拉列表选择字体，并用当前字体渲染独立预览窗口。扫描失败不阻塞编辑，回退到微软雅黑。

### 发布账号连接

- 点击“添加账号”先选择平台和备注。
- 保存后立即创建独立 Chromium persistent context 并打开平台创作者页面。
- 弹窗转为登录状态面板：正在打开、等待扫码、检测登录、已连接、需要用户处理、失败。
- 验证码和风控只提示用户接管，不自动绕过。
- 已有账号支持“打开登录窗口”“检测状态”“删除”。

### 脚本库与导航

- 脚本条目支持展开查看全文、编辑元数据与内容、删除。
- 长文本在列表中折叠，展开后单独滚动。
- 侧边栏使用 `position: sticky; top: 18px; height: calc(100vh - 36px)`，导航区内部可滚动，底部服务状态固定。

## UI 规范

- 页面标题 28px/700，区块标题 18px/700，正文 14px，说明文字 12px。
- 主按钮高度 42px，圆角 12px；小按钮高度 34px，圆角 10px。
- 卡片圆角 20px，内部留白 24px，模块间距 20px。
- 输入控件高度 42px，圆角 10px。
- 主色：袋研官黄；强调按钮：黑底白字；禁用态保持可读。
- 页面最大内容宽度由工作区决定，不额外压缩核心编辑区。
- 所有动态区域提供空状态、加载态、成功态和错误态。

## 数据与安全

- API Key 继续只存 Windows Credential Manager。
- 草稿、日志和错误提示不得包含密钥。
- 发布浏览器上下文按账号隔离。
- 字体扫描只读取系统字体目录，不修改字体文件。
- AI 生成、声音克隆和平台登录均设置超时，支持用户重试。

## 测试与验收

1. 未配置百炼密钥时，生成选题必须在 1 秒内显示中文错误和“前往设置”入口。
2. 使用 Mock 百炼成功返回时显示五个选题；超时、401、404 模型错误都有不同引导。
3. 音色与情感除模型名外均显示中文；上传样本可完成校验和克隆状态流转。
4. 无音频、已有音频和恢复旧草稿三种情况下镜头区都可操作。
5. 系统字体列表可搜索，选择后预览与输出样式快照同步。
6. 模板可新建、编辑、复制、应用和保存。
7. 添加发布账号后立即打开独立登录窗口并显示连接状态。
8. 脚本可展开预览和编辑。
9. 页面滚动到底部时侧边栏仍完整可见。
10. 使用打包后的 Windows 程序完成真实启动和主要页面 GUI 验收。
