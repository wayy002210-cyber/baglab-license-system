# 文案与平台定时发布可靠性设计

## 目标

修复文案、归档版本、文字样式、字体和混音状态问题，并把发布流程完善为：立即打开抖音或视频号后台、上传成片、填写标题与话题、选择平台定时发布、提交并验证结果。未指定时间时使用当前时间后 20 分钟。

## 文案与发音

- AI 文案输出为可直接朗读的第一人称口播稿，每行 10–25 个汉字并以中文标点结尾。
- 过短语义片段与相邻句合并；过长句优先在逗号、顿号和语义边界拆分，不能丢字。
- 违禁词检查是本地规则服务，不依赖百炼 Key；错误必须显示本地服务、请求校验或数据保存的具体阶段。
- 增加用户可维护的发音词典。字幕和文案保留原词，发送 MiniMax 前生成独立发音稿，避免改动屏幕文字。

## 编辑状态

- 归档文案“复制新版本编辑”创建 review 状态的新项目，自动切换到自定义文案页并回填标题、正文和来源信息。
- 人声音量由草稿/媒体设置持久化，组件不得传入固定常量。
- 字幕与标题预览统一使用 CSS 可表达的描边和阴影模型；模糊度为零偏移时仍可见。
- Windows 字体名称通过 PowerShell 以 UTF-8 JSON 获取，避免 reg.exe 控制台代码页造成乱码；选中字体加载真实文件。

## 平台定时发布

- 发布任务包含 `scheduledAt`；为空时创建任务即冻结为当前时间后 20 分钟。
- Electron 调度器立即领取新任务，而不是等到计划时间。平台页面负责保存定时计划。
- `PublishRequest` 携带标题、话题、平台计划时间和时区。
- 抖音和视频号分别实现定时发布选择器与日期时间填写逻辑，上传完成后等待页面就绪，再填写内容与定时选项。
- 点击最终发布后，必须检测明确成功提示或作品管理页状态才标记成功。
- 登录失效、验证码、风控或页面结构变化进入 `needs_user`，保留浏览器上下文、截图和当前 URL，不绕过验证。

## 验收

- 文案短句、标点、违禁词、归档复制、字体中文名、样式预览和音量均有自动回归测试。
- 本地仿真抖音/视频号页面验证上传、标题、话题、定时时间、提交与人工接管状态。
- 全量 `npm run check` 通过，安装包内置后端健康检查通过。
