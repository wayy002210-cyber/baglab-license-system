# 发布流程安全并行设计

## 目标

缩短抖音视频发布耗时，并让进入队列及登录接管状态更直观。

## 设计

- 视频文件交给平台上传控件后，立即填写标题和话题。
- 标题和话题填写完成后，再等待平台确认视频上传完成。
- 封面、发布时间和最终发布仍必须在视频上传完成后串行执行。
- 创建发布任务后，界面自动切换到“发布队列”。
- 任务进入 `needs_user` 时显示“浏览器已打开，请完成登录后点击继续发布”。

## 约束

- 不改变封面定位和操作顺序。
- 不并行执行封面、定时设置或发布提交。
- 不打包，由用户继续在开发模式完成真实链路测试。

## 验证

- 单元测试验证元数据填写发生在上传完成等待之前。
- 前端测试或类型检查验证队列切换和登录提示。
- 发布器相关回归测试保持通过。
