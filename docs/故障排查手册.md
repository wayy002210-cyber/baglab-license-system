# 故障排查手册

## AI Key 未配置或调用失败

确认系统设置中的两项凭据均显示“已配置”，并检查账户余额、模型权限和网络。429 会自动退避重试。

## 素材无法使用

在素材中心查看错误原因。损坏、时长为零、格式不支持或 ffprobe 无法读取的文件会被隔离。确保模板引用的每个分类都有可用视频。

## 编码失败

程序按 NVENC、QSV、AMF 顺序检测硬件编码器，失败后自动回退 libx264。检查磁盘剩余空间、输出目录权限和字体是否存在。

## 发布要求人工处理

`needs_user` 表示登录失效、扫码、验证码或风控。打开对应账号完成验证，再人工重试。不要删除浏览器账号目录。

## 导出诊断

在系统设置点击“导出诊断包”。压缩 JSON 只包含脱敏日志、版本和任务元数据，不包含 API Key、Cookie、Authorization 或任务快照。
