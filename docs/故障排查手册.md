# 故障排查手册

## AI Key 未配置或调用失败

确认系统设置中的两项凭据均显示“已配置”，并检查账户余额、模型权限和网络。429 会自动退避重试。

## 素材无法使用

在素材中心查看错误原因。损坏、时长为零、格式不支持或 ffprobe 无法读取的文件会被隔离。确保模板引用的每个分类都有可用视频。

缩略图为空不代表视频不可用。缩略图生成失败会被单独降级，重新扫描时会按素材指纹复用已有缓存。

## 编码失败

程序按 NVENC、QSV、AMF 顺序检测硬件编码器，失败后自动回退 libx264。检查磁盘剩余空间、输出目录权限和字体是否存在。

任务编码进度至少每 5 秒刷新一次。只有 ffprobe 验证视频流、音频流、时长和文件大小全部有效后，任务才会显示“已完成”。失败任务的 ASS 和中间文件保留在“系统设置”指定的工作目录中，成品目录不会出现无法播放的 partial 文件。

## 字幕越界或字体缺失

新任务会自动语义折行。旧任务重试仍使用旧快照；如需应用新标题或字幕样式，请从归档文案复制新版本后重新创建任务。

字体列表来自 `C:\Windows\Fonts`、当前用户字体目录和字体注册表。若某个旧式位图字体可以选中但 FFmpeg 无法渲染，请改用 TTF、OTF、TTC 或 OTC 轮廓字体。

## 成片预览不播放

先点击“打开成片”确认文件存在，再重新选择该任务。播放器通过应用媒体协议读取文件，支持中文和空格路径。若文件被外部程序移动或删除，任务记录不会自动改写路径，需要重新生成或把文件恢复到原位置。

## MiniMax 配音失败

`rate limit exceeded (RPM)` 表示每分钟请求数达到账号上限，软件会自动指数退避；批量队列仍保持串行。余额不足、密钥无效、音色无权限、网络超时等错误会直接显示中文原因和处理建议。

## 发布要求人工处理

`needs_user` 表示登录失效、扫码、验证码或风控。打开对应账号完成验证，再人工重试。不要删除浏览器账号目录。

## 导出诊断

在系统设置点击“导出诊断包”。压缩 JSON 只包含脱敏日志、版本和任务元数据，不包含 API Key、Cookie、Authorization 或任务快照。

日志记录生成阶段、发布领取和最终状态，默认位于应用数据目录并自动轮转。若需要提交问题，请优先提供诊断包，不要提供浏览器账号目录。
