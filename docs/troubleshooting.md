# 故障排查

## 任务停在“编码成片”

新版任务中心会把 FFmpeg 的实际导出进度映射到 75%–99%。如果进度超过 60 秒完全不变化：

1. 在系统设置中导出诊断包。
2. 检查输出目录剩余空间是否高于 5 GB。
3. 将编码器暂时切换为“自动”后重试。
4. 自动模式会依次执行短试编码，只使用真正可工作的 AMF、NVENC 或 QSV；全部不可用时回退 `libx264`。

程序会持续读取 FFmpeg 的进度和错误输出，避免输出管道写满后卡死。失败信息保留最后 200 行 FFmpeg 错误，便于定位素材、字幕字体或编码器问题。

## 分镜配音失败

配音按镜头逐段生成，失败提示会包含具体镜头序号。检查 MiniMax 密钥、账户余额、音色权限和网络后，可以重新生成全部分镜配音；已命中本地缓存的段落不会重复消耗额度。
