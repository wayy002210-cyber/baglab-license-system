# 开发说明

## 环境

- Windows 11 x64
- Node.js 24
- Python 3.11
- FFmpeg 8

依赖安装与构建命令见根目录 README。`npm run check` 会依次执行 TypeScript 检查、Vitest、Pytest 和生产构建。

## 目录

- `electron/`：主进程、Preload、SQLite Repository、调度与诊断
- `src/renderer/`：Vue 3 页面与组件
- `backend/app/`：FastAPI、AI、媒体、任务和发布服务
- `backend/tests/`、`tests/`：Python 与 Electron/Vue 测试
- `scripts/`：运行时准备和安装包验证

## 开发约束

- Renderer 不得启用 NodeIntegration。
- API Key 只能通过 Credential Manager 和临时请求头传递。
- 任务快照禁止包含 Key、Token、Cookie、Authorization 或密码。
- 数据库变更必须加入迁移。
- 平台页面变化只修改 Publisher Adapter 或页面封装。
- 新功能先写失败测试，再实现并运行 `npm run check`。

## 产物验证

```powershell
node scripts/verify-packaged-backend.mjs
node scripts/verify-unpacked-app.mjs
node scripts/verify-installer.mjs
```
