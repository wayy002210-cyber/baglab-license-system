## 需要用户完成的外部验收

1. 当前 Windows 凭据库中的百炼密钥已被百炼返回 `invalid_api_key`。请在系统设置中保存新密钥，再点击“测试百炼与当前模型”。
2. 百炼连接正常后，完成一次“生成选题 → 生成文案 → 保存进入音频制作”。
3. 使用准备好的声音素材完成一次 MiniMax 克隆。克隆试听和正式配音可能按 MiniMax 规则计费，因此未由自动验收代替用户执行。
4. 在“发布账号”分别创建抖音、视频号账号卡片，点击卡片后在独立浏览器中手动扫码。
5. 各平台先验证一次草稿，再验证一次测试发布和排期。验证码及平台风控必须人工处理。

上述步骤涉及真实第三方凭据、计费调用、扫码和对外发布，软件不会自动绕过或代替用户确认。
