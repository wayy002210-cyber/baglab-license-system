# 外部服务验收清单

以下步骤需要真实账号或 API 凭据，安装包和自动化测试不会内置这些信息。

## 百炼与 MiniMax

1. 在“系统设置”分别保存百炼和 MiniMax API Key。
2. 在“任务中心”加载 MiniMax 音色并完成一次试听。
3. 使用包含明确品牌事实的 Persona 创建一条任务。
4. 检查百炼返回的逐镜头文案没有新增未经提供的价格、资质、销量或承诺。
5. 断网或使用无效 Key 再执行一次，确认任务显示具体失败阶段且可以重试。

## 抖音

1. 在“发布账号”新增测试账号并点击登录/检测。
2. 在打开的独立 Chromium 窗口手动扫码；验证码和风控由人工完成。
3. 选择一条测试成片，先验证草稿流程，再验证一次真实发布。
4. 检查标题、话题、视频和可选封面正确，成功状态只在平台明确返回成功后写入。

## 小红书

按抖音相同步骤执行。若页面选择器变化，保留诊断包、脱敏截图和页面 URL，只调整小红书 Publisher Adapter。

## 验收记录

记录测试时间、平台账号别名、任务 ID、发布任务 ID和结果。不要在记录中粘贴 API Key、Cookie、Authorization、二维码或浏览器账号目录内容。
