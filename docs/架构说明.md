# 架构说明

Electron Main 是可信边界，负责 SQLite、Credential Manager、白名单 IPC、Python 生命周期、任务状态同步和发布调度。Preload 使用 Zod 校验双向数据。Vue Renderer 只调用 `window.autocut`。

Python FastAPI 仅监听 `127.0.0.1` 随机端口，所有接口要求 256 位会话令牌。生成链路为：

```text
持久化任务
  → 百炼结构化文案
  → MiniMax 三并发配音与缓存
  → 固定种子素材选择
  → 视频/配音/字幕/BGM 时间线
  → 单实例 FFmpeg 编码
  → SSE 事件
  → SQLite 状态与成片路径
```

发布链路为：

```text
发布排期 → 15 秒调度 → 同账号串行领取
→ 独立 Chromium persistent context
→ 抖音/小红书 Publisher Adapter
→ published / failed / needs_user
```

运行时密钥不写入 SQLite、LocalStorage、任务快照、SSE 或日志。日志和诊断包会再次执行递归脱敏。
