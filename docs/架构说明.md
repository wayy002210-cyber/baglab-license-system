# 架构说明

Electron Main 是可信边界，负责 SQLite、Credential Manager、白名单 IPC、Python 生命周期、任务状态同步和发布调度。Preload 使用 Zod 校验双向数据。Vue Renderer 只调用 `window.autocut`。

成片和素材缩略图通过 `autocut-media` 自定义协议读取。主进程会用数据库中的任务或素材 ID 反查白名单路径，Renderer 不能提交任意本地路径。

Python FastAPI 仅监听 `127.0.0.1` 随机端口，所有接口要求 256 位会话令牌。生成链路为：

```text
持久化任务
  → 百炼结构化文案
  → MiniMax 三并发配音与缓存
  → 固定种子素材选择
  → 视频/配音/字幕/BGM 时间线
  → 单实例 FFmpeg 编码
  → SSE 事件
  → SQLite 状态与成片路径
```

发布链路为：

```text
发布排期 → 15 秒调度 → 同账号串行领取
→ 独立 Chromium persistent context
→ 抖音/视频号 Publisher Adapter
→ published / failed / needs_user
```

待领取任务可在 SQLite 状态机中原子取消。执行中任务通过 FastAPI 协作取消令牌，在点击平台“发布”前停止；提交开始后取消接口返回冲突，避免平台已提交而本地状态被误置为取消。

运行时密钥不写入 SQLite、LocalStorage、任务快照、SSE 或日志。日志和诊断包会再次执行递归脱敏。
