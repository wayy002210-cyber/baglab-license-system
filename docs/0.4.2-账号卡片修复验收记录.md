# 0.4.2 账号卡片修复验收记录

## 根因

发布账号页面把 Vue `reactive` 生成的代理对象直接传入 Electron
`contextBridge`。该代理对象无法被结构化克隆，调用在进入主进程和写入
SQLite 之前即失败，因此界面显示“账号登录连接失败”。

## 修复

- 在 Renderer 中把表单转换为只包含 `name`、`platform` 的普通对象后再调用 IPC。
- 账号名称在提交前统一去除首尾空格。
- 创建阶段的兜底提示改为“创建账号卡片失败”，避免与后续登录阶段混淆。
- 增加表单转换回归测试。

## 验收结果

- 在 0.4.2 打包应用中完成“添加账号 → 填写名称 → 创建账号卡片”真实界面操作。
- 账号成功写入 SQLite，页面出现账号卡片及“打开登录窗口”按钮。
- 页面提示“账号卡片已创建，请点击卡片打开登录窗口”。
- 打包后端健康检查通过。
- 打包桌面程序窗口启动检查通过。
- 回归测试通过。
