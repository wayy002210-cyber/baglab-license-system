# 0.4.3 文案生成与任务音色修复验收记录

## 文案生成失败根因

百炼连接和 `deepseek-v3` 模型本身可用。失败发生在模型偶发返回超过五个
候选项、字段首尾带空格或字段略超长度时。旧实现把这种可恢复的格式偏差
直接判定为结构校验失败；连续三次后虽然后端返回 502，但前端没有匹配该
英文错误，因此最终只显示笼统的“生成选题失败”。

## 修复内容

- 对模型返回的选题先执行安全归一化：去除空白、去重、限制字段长度并取
  前五个有效候选项。
- 有效候选项不足五个时仍保留重试和严格校验，防止把残缺内容交给用户。
- 将模型结构校验错误翻译为明确中文，说明 DeepSeek 已响应，并提供
  “重新生成”或切换 `qwen-plus` 的处理建议。
- 任务中心与音频制作共用同一音色筛选函数：全部个人克隆音色优先，加上
  最多十个中文官方基础音色。
- 任务中心的音色名称统一使用中文显示名称。

## 验收
