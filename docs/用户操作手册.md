# 用户操作手册

1. 在“系统设置”保存百炼和 MiniMax API Key。
2. 在“账号档案”建立品牌事实、语气、CTA 和禁用词。
3. 将视频按产品、人物、环境、服务过程等目录分类，在“素材中心”逐类扫描。
4. 在“文案生成”选择 Persona，生成选题和口播稿，或粘贴自己的文案；确认后保存进入音频制作。
5. 在“音频制作”以卡片选择或试听音色，设置情感、语速和音调，生成并试听整条口播音频。
6. 在“镜头剪辑”选择模板，将文案拆成镜头，指定素材分类并调整人声、BGM、标题和字幕；也可按当前结构一键改写文案。
7. 创建任务后，在“任务中心”等待选片和编码完成；失败任务可重试，完成后可预览或打开成片目录。
8. 在“发布账号”先创建抖音或视频号账号卡片，再点击卡片打开独立浏览器并手动扫码。
9. 在“发布排期”选择已完成成片、账号、标题、话题和时间。

待发布、已排期或上传准备阶段的任务可以取消。软件会在点击平台“发布”前进行协作取消；平台提交已经开始后会拒绝取消，避免平台已提交但本地误报取消。

验证码、扫码、安全验证或平台风控必须由用户在浏览器中完成。软件不会绕过平台验证。

输出默认为系统“视频/袋研官混剪成片”目录，格式为 1080×1920、30fps、H.264/AAC MP4。输出目录、工作目录、编码器和码率可在“系统设置”调整；当前作品的字幕字体、标题、BGM 与混音在“镜头剪辑”调整。
