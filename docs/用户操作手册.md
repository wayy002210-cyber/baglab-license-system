# 用户操作手册

1. 在“系统设置”保存百炼和 MiniMax API Key。
2. 在“账号档案”建立品牌事实、语气、CTA 和禁用词。
3. 将视频按产品、人物、环境、服务过程等目录分类，在“素材中心”逐类扫描。
4. 在“镜头模板”检查镜头角色、素材分类与时长策略；模板可导入或导出 JSON。
5. 在“任务中心”选择 Persona、模板、MiniMax 音色和生成数量。
6. 可先试听音色，再等待文案、配音、选片和编码完成；失败任务可重试，完成后可直接预览或打开成片目录。
7. 在“发布账号”添加抖音或小红书账号，点击“登录/检测”，在独立浏览器中手动扫码。
8. 在“发布排期”选择已完成成片、账号、标题、话题和时间。

待发布、已排期或上传准备阶段的任务可以取消。软件会在点击平台“发布”前进行协作取消；平台提交已经开始后会拒绝取消，避免平台已提交但本地误报取消。

验证码、扫码、安全验证或平台风控必须由用户在浏览器中完成。软件不会绕过平台验证。

输出默认为系统“视频/袋研官混剪成片”目录，格式为 1080×1920、30fps、H.264/AAC MP4。输出目录、工作目录、编码器、码率、字幕字体和 BGM 可在“系统设置”调整。
