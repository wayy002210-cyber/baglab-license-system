# 用户操作手册

## 批量生产流程

1. 在“系统设置”保存百炼和 MiniMax API Key，并设置成品目录、工作目录与编码器。
2. 在“账号档案”维护品牌事实、语气、CTA 和禁用词。
3. 在“素材中心”按产品、人物、生产过程、环境等分类扫描本地视频。
4. 在“文案生成”生成 5 条选题。每条包含 5–8 字短标题和选题详情，可全选或多选批量生成文案。
5. 检查口播文案并执行违禁词检查，确认后收进文案库。归档文案可复制为新版本继续修改，旧任务不受影响。
6. 在“音频设置”选择或克隆音色，设置情感、语速和音调。
7. 在“镜头剪辑”选择当前或全部文案自动拆镜，检查每句台词推荐的素材分类，再设置人声音量、BGM、标题与字幕样式。
8. 创建当前或全部脚本任务。任务先进入“待合成”，不会提前消耗 MiniMax 额度。
9. 在“任务中心”启动单条或“一键合成所有任务”。队列严格串行，可在当前任务完成后暂停并继续。
10. 成片完成后可在右侧固定播放器预览，或点击“打开成品文件夹”。

## 标题、字幕与字体

- 短标题固定为 5–8 个汉字，贯穿选题、文案库、任务、发布资料、顶部标题和 MP4 文件名。
- 长字幕会根据画布、字号、缩放和描边自动按语义折成最多两行；更长内容会拆成连续字幕事件。
- 字体下拉框扫描系统和当前用户字体，支持 TTF、OTF、TTC、OTC、FON、FNT，也可以手动选择文件。
- 样式预览可在工厂场景背景和深色背景间切换。预览背景只用于查看描边、阴影效果，不写入成片。
- ASS、partial 文件和任务诊断内容存放在工作目录；成品目录只保留可播放的最终 MP4。

## 发布

发布账号支持抖音和视频号。首次连接会打开独立浏览器，由用户手动扫码；验证码、安全验证和平台风控必须由用户接管，软件不会绕过验证。

输出默认为系统“视频/袋研官混剪成片”，格式为 1080×1920、30fps、H.264/AAC MP4。
